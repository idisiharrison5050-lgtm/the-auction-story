# The Auction — Chat Image Archive

This manifest records the auction-related image assets currently available from this ChatGPT production workspace.

The image binaries are packaged separately because the connected GitHub file writer can write UTF-8 text but cannot directly transfer local binary image files into repository contents.

## Archive

The compressed archive contains the available auction-related images from this chat workspace (48 images, excluding the unrelated `React.jpg`).

## Purpose

These assets are raw visual references and generated production material. They are not all canonical shots; the canonical story/continuity files remain authoritative when an image conflicts with the restarted production plan.

## Production rule

Use the locked character references and canonical shot sequence in `CONTINUITY.md` and `PRODUCTION/SHOT_LIST.md`. Earlier incorrect bidder/character generations are retained only as archived raw material and must not silently become canon.
