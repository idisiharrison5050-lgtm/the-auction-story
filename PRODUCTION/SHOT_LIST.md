## Production rules
- One shot at a time.
- Before creating a shot, verify: **who is in frame, whose turn it is, what was just said, what happens immediately afterward, and which established face/reference must be used.**
- Never agree to a proposed shot if it conflicts with the locked story. The story/continuity takes priority over convenience.
- Use existing reference images whenever suitable. Only generate a new image when the required composition cannot be obtained from an existing reference.
- For image-to-video prompts, explicitly state whether dialogue is allowed. Silent shots must say **NO DIALOGUE** and prohibit all speech. Dialogue shots must specify the exact words and prohibit additional dialogue.
- If a video model rejects a generation, first change composition/camera angle or simplify the prompt before unnecessarily changing an established character.
- Target a cinematic stylized-realism/3D animated-film look: realistic proportions, natural human movement, professional cinema-camera feel, not cartoonish and not live-action-identifiable.
