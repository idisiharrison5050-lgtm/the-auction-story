### Future auction shots
Build only as needed. Do not generate every bid as a long standalone clip. Use cuts, brief reaction shots and sound design to create the feeling of rapid escalation.

## Canon auction amounts
$500 → $1,000 → $5,000 → $100,000 → eventually $500,000.

## Production rule
One shot at a time. If a generated clip is good even if it contains a small improvisation, evaluate whether it can be incorporated without breaking canon before regenerating it.

## Video-prompt rule
Every image-to-video prompt must explicitly state the dialogue policy. If a shot is silent, say **NO DIALOGUE** and prohibit all characters from speaking. If a shot has dialogue, specify the exact words and state that no other dialogue is allowed.

## Reference-image rule
When an existing reference image is already suitable, identify and reuse it instead of generating a new image unnecessarily. When a new image is required, provide a text-to-image prompt that makes the intended shot clear. Change camera angle/composition before repeatedly changing faces when a video-model generation is being rejected.
